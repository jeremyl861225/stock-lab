# stock-lab — 股市預測驗證系統

每天對市值前 50 大台股產生「未來 5 日 / 20 日上漲機率」預測，把預測**事前鎖死**，
到期後自動對答案，並與笨基準線並排計分。

**這個系統的目的不是賺錢，是防止自我欺騙。**
人腦有後見之明偏誤：三個月後你只會記得自己看對的那幾次。唯一的解法是把預測寫下來、
鎖起來、然後誠實地對答案。

---

## 為什麼多數這類系統是自欺

失敗幾乎從不是「模型不夠聰明」，而是驗證環節在騙自己。本系統用四道結構性防線：

| 防線 | 做法 | 程式位置 |
|---|---|---|
| 預測不可竄改 | `predictions.jsonl` 只准 append；同一組 (日期,期間,模型,標的) 只能有一筆，重跑不覆寫；每筆帶 `feature_hash` | `src/predict.py` |
| 必有笨基準線 | `always_up` / `random` / `momentum` 每天照常出手，永不關閉 | `src/models/baselines.py` |
| 禁止未來函數 | 特徵一律 rolling/shift；訓練集截止日 = `as_of − horizon`（標籤要 horizon 天後才實現）；7 個測試逐日驗證 | `src/features/build.py`、`tests/` |
| 顯著性要誠實 | 橫斷面 t 值依樣本重疊倍數折減後才判讀 | `src/crosssec.py` |

## 目前的發現（2024-08 ~ 2026-09 回測）

**一、用方向準確率看，所有模型都輸給「無腦猜漲」**

| 期間 | always_up | stat_logit | stat_gbdt | momentum | random |
|---|---|---|---|---|---|
| 5 日 | **58.4%** | 54.4% | 55.7% | 52.7% | 51.0% |
| 20 日 | **67.1%** | 63.0% | 58.9% | 54.6% | 49.9% |

過去兩年是大多頭（台積電 948 → 2,380），猜漲的基本率本來就高達 58–67%。
`stat_logit` 的 63% 單看很體面，但同期基準線是 67.1% —— **沒有基準線就會誤判**。

**二、改用橫斷面（選股能力）看，訊號出現了，但撐不住統計檢驗**

| 期間 | 模型 | RankIC | 前20%−後20% | 名目 t | 有效 n | **調整 t** |
|---|---|---|---|---|---|---|
| 20 日 | stat_logit | +0.160 | **+9.35%** | 3.59 | 11.8 | **1.79** |
| 20 日 | momentum | +0.107 | +5.33% | 3.47 | 11.8 | **1.74** |
| 5 日 | stat_logit | +0.067 | +2.33% | 1.77 | 50.0 | **1.77** |

「前 20% 比後 20% 多漲 9.35%」很誘人，名目 t=3.59 看似高度顯著。
但 20 日期間每 5 天取樣一次，相鄰樣本重疊 4 倍，有效樣本只有約 12 個 ——
調整後 t=1.79，**不顯著**。

> 現階段的誠實結論：**沒有任何模型具備經得起檢驗的選股能力。**
> 這正是系統該給出的答案，也是它存在的價值。

## 使用

```bash
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
./.venv/bin/python src/collect/universe.py   # 建 universe（市值前 50）
./.venv/bin/python src/collect/finmind.py    # 回補兩年價量／法人／融資券
./.venv/bin/python src/features/panel.py     # 組 panel
./.venv/bin/python src/predict.py            # 產生今日預測
./.venv/bin/python src/settle.py             # 結算到期預測
./.venv/bin/python src/report.py             # 產生 docs/index.html
./.venv/bin/python -m pytest tests/ -q       # 未來函數防線
```

GitHub Actions 每個交易日台北 18:00 自動跑完上述流程並 commit，
**git 歷史本身就是預測不可竄改的證明**。

啟用 LLM 模型：在 repo secrets 設 `ANTHROPIC_API_KEY` 或 `GEMINI_API_KEY`
（未設定時自動跳過，不影響其他模型）。

## 資料來源

| 來源 | 內容 | 備註 |
|---|---|---|
| FinMind | 價量、三大法人、融資券 | 一次請求取回整段歷史 |
| TWSE OpenAPI | 上市公司股數 → 市值 | 用於建 universe |
| Google News RSS | 個股與大盤財經新聞 | 供 LLM 模型使用 |

**不要用 TWSE 的 `STOCK_DAY` 抓歷史**：一次只給一檔一個月，兩年 50 檔要 1,250 個請求，
且限流極嚴 —— 實測先回 307（重導到「因為安全性考量」頁），再密集就變 428，
最後整個 IP 被冷凍。FinMind 150 個請求、89 秒解決同一件事。

## 限制

1. **LLM 無法回測** —— 它知道歷史結果，任何回測分數都是假的。只能從上線日往後累積。
2. **研究者自由度** —— 特徵與模型是我事後挑的，walk-forward 消除不了這個偏誤。
3. **交易成本未計** —— 即使找到 edge，扣掉手續費與證交稅後未必有利可圖。
4. 本專案是研究與紀律工具，**不構成投資建議**。
