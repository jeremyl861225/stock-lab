# 幅度是怎麼算出來的

獲利點與停損點不是憑感覺定的，也不是技術分析的支撐壓力位，
而是從波動度推導的統計區間。這份文件說明推導、實測結果，以及它的限制。

## 推導

$$\sigma_h = \sigma_{\text{daily}} \times \sqrt{h}$$

波動隨時間的平方根縮放，這是隨機漫步的標準性質。`σ_daily` 用 20 日已實現波動。

| 數字 | 公式 | 值 |
|---|---|---|
| 上漲情境的平均幅度 | $E[r \mid r>0] = \sigma\sqrt{2/\pi}$ | $0.798\sigma$ → 取 **0.8σ** |
| 下檔 10% 分位 | $z_{0.10}$ | $-1.2816\sigma$ → 取 **0.8 × 1.6 = 1.28σ** |

- **獲利點** = 收盤 × (1 + 0.8σ × (1+skew))　條件期望，合理可達
- **停損點** = 收盤 × (1 − 1.28σ × (1−skew))　正常波動之外，跌破才代表判斷錯了

停損刻意不用條件期望跌幅：那正好是下跌情境的中心值，
約有一半機率被正常波動掃到，拿來當停損會被反覆洗出場。

## 實測（48,898 筆 20 日樣本）

把實際報酬用 `σ_daily × √h` 標準化後：

| 指標 | 常態理論 | 實測（20 日） |
|---|---|---|
| 峰度 | 0 | **+4.86**（明顯肥尾） |
| 跌破 −1.28σ 的比例 | 10% | **6.6%** |
| 跌破 −2.33σ 的比例 | 1% | **1.5%** |
| 上漲時平均幅度 | 0.798σ | **1.075σ** |

三個發現：

1. **肥尾確實存在**（峰度 +4.86）。極端事件比常態預測的多 ——
   跌破 −2.33σ 的實際比例是理論的 1.5 倍。
2. **但整體分布右移**：標準化報酬的均值是 +0.348，不是 0。
   所以左尾被觸及的比例反而低於理論（6.6% < 10%）。
3. **上漲幅度被低估**：實測 1.075σ，高於理論的 0.798σ。

## 為什麼不照實測值校準

看起來應該把係數從 0.8 調到 1.075、把停損從 −1.28σ 調到 −1.01σ。**但不能。**

那個 +0.348 的均值偏移，有相當部分來自**生存者偏差**：
本專案的 universe 是「今天」的市值前 50，這批股票兩年等權 **+272%、49/50 上漲**。
用這個樣本去校準參數，等於把選股偏差固化進模型 ——
未來若市場轉空，這組被「校準」過的參數會系統性高估上檔、低估下檔。

**在生存者偏差修好之前，保持理論值（中性）比照實測校準更安全。**
肥尾是真實的、與偏差無關的發現，但它的影響方向是「極端事件更多」，
而理論值在尾端本來就偏保守，不會因此低估風險。

## 已知限制

1. **常態假設**：實測峰度 +4.86，尾端比常態厚。更嚴謹的做法是用經驗分位數、
   GARCH 預測波動、或 EVT 處理尾端 —— 但都要等有無偏樣本才有意義。
2. **已實現波動預測未來波動**：波動有叢集性，20 日已實現波動對未來的預測力有限。
3. **skew 是主觀的**：不對稱來自判斷，不是統計推導。
4. **不含交易成本**：獲利點與停損點都是毛報酬位置。
