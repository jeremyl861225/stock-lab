（樣本未達 8 筆顯示「—」，因為 3 筆對 2 筆不代表 67% 的準確率）
獲利點 = 收盤 ×(1+漲幅)，漲幅為「上漲情境下的平均幅度」（5／20 日）
停損點 = 收盤 ×(1+下檔10%分位)，設在正常波動之外，跌破才代表判斷錯了（5／20 日）
年化波動 = 近 20 日報酬標準差 ×√252，決定上面兩個價位拉多開
（原「賠率比」已移除：它把五成機率的目標除以一成機率的尾部，200 筆全部 <1，不帶資訊）
排序依期望值 = P(漲)×漲幅 + P(跌)×跌幅
一年期分頁不顯示獲利點與停損點，改為中位價與五成區間。原因是實測： 目標價與 σ 的相關是 +0.97、與 P漲 只有 +0.05，把所有標的的 P漲 換成同一個值， 目標價的差異只掉 1% —— 那是波動度的讀數不是判斷。 而它並不是太寬：過去一年南電實際高/低 7.9 倍、南亞科 10.1 倍，模型只有約 3 倍， 所以縮窄會讓它同時變成沒用又錯的數字。改的是顯示什麼，不是分布

五成區間 = 一年後有一半機率落在這裡，寬度由波動度決定
一年期的期望值也是中位數（不是平均數 —— 平均數含 exp(σ²/2)， 會讓排序退化成純波動度排序）
