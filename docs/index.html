信心是判斷當下的把握，準確率是該檔過去預測的期望值加權命中率
（樣本未達 8 筆顯示「—」，因為 3 筆對 2 筆不代表 67% 的準確率）
獲利點 = 收盤 ×(1+漲幅)，漲幅為「上漲情境下的平均幅度」
停損點 = 收盤 ×(1+下檔10%分位)，設在正常波動之外，跌破才代表判斷錯了
賠率比 =（獲利點−收盤）÷（收盤−停損點），量的就是卡片上這兩個價位
它通常小於 1，因為獲利點用「合理可達」的條件期望、停損點用「正常波動之外」的分位數
排序依期望值 = P(漲)×漲幅 + P(跌)×跌幅
